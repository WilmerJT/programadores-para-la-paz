¿Por qué es importante que los proyectos de software mantengan 
un registro de cambios usando herramientas como Git?

Es importante que los proyectos de software mantengan un registro 
de los cambios usando herramientas como Git porque así se puede ver el
avance de estos a través del tiempo y registrar cada cambio hace posible 
que si hay algún error poder evidenciar con facilidad en qué momento 
es que este paso y poder corregirlo de manera que no se tenga que revisar 
todo el código para encontrarlo. Así se mantiene una organización clara y 
efectiva para todos los que estén trabajando en el proyecto.
